## 第二章 项目概况——它想做什么

### 2.1 一个169KB级别的野心

如果把 GitHub 仓库的体积当作野心的度量衡，Folunar_ 是一个拥有近 600MB 代码体量的项目——这还不包括它已经完成的前传 [Trahexa](https://github.com/Chillizu/Trahexa)。然而它的 README 只有一句话，Star 数为零。这种"代码的丰满与社交认可的空洞"之间的巨大反差，本身就值得玩味。

Folunar_ 试图构建的是一个极其大胆的东西：**一个无需人类监督、自主在 Docker 沙箱中探索 Linux 世界、持续学习、且每次行为都不尽相同的 AI Agent**。不是 ChatGPT 那样的对话机器人，不是 AutoGPT 那样的任务执行器，而是一个真正意义上的"数字生命体"——它自己决定做什么，自己从失败中学习，自己发现知识，甚至自己产生"好奇心"。

项目的核心哲学被凝练为一句话：**"思考的本质 = 概率 + 最优选择"**。这个公式暗示了一种认知观的底层信仰：智能不是神秘的灵魂之火，而是概率分布在决策空间中的优化过程。这个目标设定在学术层面上与 DeepMind 的通用智能研究和 Yann LeCun 的 JEPA 架构遥相呼应，只是实现者是一个个人开发者。

### 2.2 技术路线的七拐八弯

Folunar_ 并非一蹴而就。它的技术路线是一部小模型创业的"苦难行军"，每一步都踩坑，每一步都转弯。

**第一阶段 Trahexa** 尝试用 Qwen/DeepSeek 做 SFT+GRPO 训练，让大语言模型在沙箱中自主行动。结果失败了——数据不够，算力不够，模型太大跑不动。

**第二阶段 Folunar_** 转向小模型路线，经历了令人眼花缭乱的技术迭代：

- **GRU 7.6M**：从循环神经网络起步，发现能力不够
- **Mamba 7.3M → 12.6M → 19.7M**：切换到状态空间模型，三次扩参，每次都在追赶一个更宏伟的目标
- **MTP（Multi-Token Prediction）**：尝试让模型一次预测多个 token，提高信息密度
- **SlotMind**：引入槽位注意力机制，试图让模型学会"关注什么"
- **ModelCluster 46M**：试图从零生成 bash 命令文本，失败——"数据和容量不够"
- **最终转向"Brain+Hand"架构**：小模型（分类器/Conductor 做决策，Mamba 7.6M）+ 模板引擎（Hand 执行命令）+ LLM（仅用于自省和创作，频率极低）

这个技术路线的演进，读起来像是一部微缩版的 AI 创业史：从大模型梦到小模型现实主义，从端到端生成到模块化分工，从理想主义的"一模型搞定一切"到实用主义的"多个小模型各司其职"。唯一不同的是，所有这些决策都是由一个开发者在一到两个月内做出的。

### 2.3 当前架构与关键数据

截至 2026 年 7 月，项目处于 **P10-P20 阶段**，代码库包含 **162 个 Python 文件**，核心主循环 `online_agent.py` 已经膨胀到 **3723 行**（AGENTS.md 中记载的"2600+行"显然已经过时，像是一个快速生长的生物体，任何静态描述都追不上它的变化）。

项目自称为拥有 **20+ 个认知模块** 的 Agent 系统，涵盖从感知、意图分类、目标生成、知识图谱（FactGraph）、想象力引擎、推理层到自我意识层的完整认知架构。每个模块都有自己的 Python 文件和独立的职责。

官方报告的关键运行数据如下：

| 指标 | 数值 | 解读 |
|------|------|------|
| 马拉松步数 | 27,799 步 | Agent 在 Docker 沙箱中连续执行的步数，不是训练步数 |
| 成功率 | 92.2% | bash 命令成功执行的比例 |
| 命令自发现 | 418/418 | 系统自行发现的 Linux 命令，100% 覆盖 |
| FactGraph 节点数 | ~200 | 从命令输出中提取的事实节点数 |

这些数字的含义需要辩证看待。92.2% 的 bash 命令成功率听起来令人印象深刻，但如果这些命令大多数是 `cat /proc/cpuinfo` 和 `ls /etc`，那么这个"成功率"更像是一个打字员的速度指标而非智能的度量。27,799 步马拉松连续运行固然体现了系统的稳定性，但"连续"与"有意义"之间隔着巨大的鸿沟。418 个命令 100% 自发现——这到底是智能的体现，还是一个穷举扫描脚本的功劳？

### 2.4 一句话总结

Folunar_ 是一个个人开发者用两个月时间、从多次技术路线失败中爬出来的、试图用 700 万参数的小模型复制人类认知全栈的疯狂实验。它的数据漂亮但含义模糊，它的架构宏伟但根基薄弱，它的 README 短促但代码庞大。它就像一艘由一个船长驾驶的、在不断改装中航行的大船——没有人知道它最终能否到达彼岸，但改装日志堆满了甲板。
