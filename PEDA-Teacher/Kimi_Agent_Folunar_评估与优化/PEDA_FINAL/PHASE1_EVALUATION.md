## 2. 我的判断：报告在技术上诚实，但实验设计没有验证 PEDA 的核心假设

### 2.1 核心问题：这不是"预测误差驱动探索"，这是"完美记忆驱动导航"

**PEDA 声称要验证的假设**：当 World Model 不完美时，预测误差会驱动系统去探索不确定性区域，从而更有效地学习。

**实际验证的假设**：如果你有一个完美的 World Model，EFE-based action selection 可以在 5×5 网格中高效导航。

后者是 trivially true 的——它等价于 A* 搜索的 LLM 实现。

### 2.2 为什么预测误差没有发挥作用

代码分析（`src/phase1/drive_system.py` `compute_efe`）:

```python
# pragmatic = 到目标的曼哈顿距离 / max_dist，weight = 3.0
pragmatic = dist / max_dist  # 当接近目标时 → 0
base_efe = epistemic + pragmatic * 3.0  # pragmatic 占主导
```

当 World Model 完美时（G1=1.0）：
- `confidence = 1.0` → `epistemic_ratio = 0.0`
- `epistemic_error = ensemble_variance ≈ 0`（所有 checkpoint 预测相同）
- `curiosity_term = tanh(2.0 * 0) = 0`
- `challenge_level = 1 - confidence_avg = 0`
- `drive_adjustment ≈ 0`

所以 `EFE ≈ pragmatic * 3.0` → **纯粹的距离最小化（贪心朝向目标）**。

预测误差（epistemic）在 EFE 中的权重接近于零。系统行为与"预测误差驱动"无关——它是一个带启发式函数的贪心搜索。

### 2.3 G2/G3 的通过是预期结果，不是突破

| 指标 | 值 | 解释 |
|------|------|------|
| G2=0.1211 | 3.3步 vs 27.25步 | 完美导航当然比随机快。任何朝向目标的贪心策略都能做到。 |
| G3=0.0000 | 0% 重访率 | 贪心策略不绕路，所以不会重访。 |
| 成功率100% | 20/20 | 5×5 网格中最远距离 6-7 步，50 步限制内不可能失败。 |

这些结果在**任何**使用曼哈顿距离作为启发式的贪心策略上都能复现。它们没有证明 PEDA 的独特价值。

### 2.4 训练-评估同分布问题

报告第 6 节 L4 承认：
> "The eval uses the same random-goal/no-obstacle distribution as the training data."

训练数据：`20 configs × ~24 free cells × 4 actions = ~1920 transitions`  
评估数据：同一分布上的 20 episodes

这相当于：给学生一套题让他背，然后用同一套题考试。G1=1.0 不是学习，是**记忆**。

## 6. 下一步建议

### 必须做的：重新设计实验，真正测试核心假设

当前实验的问题是：**World Model 太完美，环境太简单，没有不确定性需要探索**。

需要引入**可控的不确定性**，让预测误差>0，然后测试系统是否能利用这个误差信号进行有效探索。

### 建议的实验 redesign（3个选项，按优先级排序）

#### 选项 A：部分训练（推荐）

**方法**：
1. 只在 5×5 网格的**一半**状态-动作对上训练 World Model（如 12 个自由格子 × 4 动作 = 48 个转移）
2. 另一半（48 个转移）作为**未知区域**
3. 评估时从**未知区域**的某个状态开始
4. 测试：预测误差是否能驱动 Agent 先去探索未知区域（收集信息），然后再利用已知信息导航到目标

**为什么这个能验证核心假设**：
- 在未知区域，WM 的预测会不准确 → 预测误差高 → epistemic drive 高
- 如果 PEDA 有效，Agent 应该**先去探索未知区域**（高 epistemic 值），然后再利用已知路径到达目标
- 如果 PEDA 无效，Agent 会**直接朝向目标**（pragmatic 主导），可能在未知区域迷路
- 对比基线：纯 pragmatic（无 epistemic）的贪心策略

**成功标准**：
- PEDA 在"部分已知"环境中到达目标的步数 < 纯 pragmatic 基线
- PEDA 的轨迹显示"先探索、后利用"的模式
- 在未知区域的停留时间 > 随机基线

#### 选项 B：动态目标

**方法**：
1. 在 5×5 网格上完全训练 World Model
2. 运行多步 episode（如 100 步）
3. 在 episode 中途**改变目标位置**（Agent 不知道目标已变）
4. 测试：当 WM 的旧预测失效时，预测误差是否能驱动 Agent 重新探索

**为什么能验证**：
- 目标改变后，WM 的旧预测会失效 → 预测误差突增
- 如果 PEDA 有效，Agent 应该开始探索以更新 World Model
- 如果 PEDA 无效，Agent 会继续走向旧目标

#### 选项 C：更大网格 + 局部训练

**方法**：
1. 在 5×5 网格上训练 World Model
2. 在 10×10 网格上评估（只有 5×5 区域是"已知"的）
3. 测试：Agent 是否能利用已知区域的信息，同时探索未知区域

**问题**：10×10 的感知表示可能需要更大的模型

## 8. 最终判断

**Phase 1 的初步验证是一个好的开始**——它证明了工程基础设施可以工作，代码没有 bug，Agent 有能力自我诚实。

**但它没有证明 PEDA 的核心假设**。当前的结果（100% 成功率, 3.3 步, 0% 重访）是任何带距离启发式的贪心策略都能做到的。

**建议**：不要宣布 Phase 1 "完成"，而是将其标记为"基础设施验证通过，核心假设验证待重设计"。用 2-3 天执行选项 A（部分训练）的实验，然后基于结果做 go/no-go 决策。

这是 WATCHDOG B1（核心假设未验证就推进）的典型案例——虽然报告自身诚实指出了限制，但"Proceed to Phase 1.5/2"的输出仍然是一个风险信号。
